There are two ways to get OpenJammer, and **the browser is the honest place to start** —
it is the whole instrument with nothing to install. Reach for the desktop app when you
want the lowest latency or to host your own VST3 / AU / CLAP plugins.

## Which one should I pick?

| | Browser (PWA) | Desktop (native) |
|---|---|---|
| **Install** | None — just open a tab | Download an installer per OS |
| **Latency** | ~15–25 ms (honest tier) | **< 5 ms** MIDI-to-audio |
| **Plugin hosting** | — | VST3 / AU / CLAP |
| **Best for** | Sketching, jamming, trying it out | Live performance, lowest latency |
| **Offline** | Works offline after first visit | Always offline |

:::tip
New here? **Play in the browser first.** When you want the lowest latency or to host the
plugins you already own, the [desktop install](/openjammer/play/install/) is one download
away. See [Browser vs native](/openjammer/play/browser-vs-native/) for the full comparison.
:::

OpenJammer is an early release — expect rough edges, and on first launch you may need to

one-time OS trust prompt for each platform.
